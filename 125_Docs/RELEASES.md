# KeepFit 1.2.0（0）

GitHub 源码版本：2026-10-28。

## 中文

- 内置 13,535 条来源可追踪的离线食物记录，支持中英文名称与别名搜索。
- 常用食物优先展示；食物和运动选择列表仅保留图标与名称，运动搜索框常显。
- 按食物基准单位计算热量与三大营养素，保留旧记录兼容及保存时的营养快照。
- 整合饮食、运动、热量平衡、体重与体脂趋势，改善不同窗口宽度下的图表与布局。
- 整理 App、图谱、后端、上架材料、设计、文档和工具目录，更新中英文 README 与仓库介绍。
- GitHub Pages 改为从整理后的文档目录发布，旧首页转至正式产品主页。

本 Release 提供源码。1.2.0（0）已分发至 TestFlight；App Store 审核草稿尚未提交，GitHub Release 不代表该版本已在 App Store 正式上架。Duo 相关布局已有模拟器检查，真机折叠、展开与旋转体验仍待验收。

验证：无签名 iOS 模拟器构建、食物图谱测试、后端测试、日期轴回归、README 链接和完整 Git 历史密钥扫描。

## English

- Includes 13,535 offline food records with source attribution and search by Chinese or English names and aliases.
- Frequently used foods appear first. Food and exercise pickers show icons and names, with an always-visible exercise search field.
- Calculates calories and macros using each food's reference unit while preserving historical records and nutrition snapshots.
- Brings food, activity, calorie balance, weight, and body-fat trends together, with layout and chart improvements across window widths.
- Organizes app, food atlas, backend, store materials, design, documentation, and tools; updates both READMEs and repository metadata.
- Publishes the relocated support and privacy pages through GitHub Actions and forwards the legacy homepage to the product website.

This release contains source code. Build 1.2.0 (0) has been distributed through TestFlight; its App Store review draft has not been submitted. A GitHub release does not establish App Store availability. Duo layouts have simulator evidence; physical-device folding, unfolding, and rotation remain pending acceptance.

Validation: unsigned iOS simulator build, food-atlas tests, backend tests, date-axis regression, README link checks, and secret scanning across Git history.
