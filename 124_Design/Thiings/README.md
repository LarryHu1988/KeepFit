# KeepFit 食材与运动图标替换方案

准备日期：2026-10-21。范围已按用户确认收敛为食材与运动；当前仅做候选选型和接入设计。

## 范围与清单

完整盘点 `SeedData.swift` 的单行及多行定义，共 **263 个食材／菜品、135 个运动项目，共 398 项**。包含常见食材库、已内置的中式菜品和营养估算菜品；不含用户自建数据。

| 选型状态 | 数量 | 含义 |
| --- | ---: | --- |
| 直接候选 | 126 | 标识名能对应官网条目；仍需检查素材实际外观 |
| 共享候选 | 117 | 同一食材形态或运动图示可以服务多个条目，如慢跑／跑步、不同强度骑行 |
| 近似候选，需确认 | 143 | 只能表示主食材、食品类别或器械，不能代表准确菜式或动作 |
| 待选型 | 12 | 当前没有找到足够可靠的对应项 |

[完整 CSV 清单](icon-mapping.csv)、[JSON 清单](icon-mapping.json)及[可搜索的审阅页面](review.html)保留每个 KeepFit ID、中文名称、分类、Thiings 名称、官网链接和匹配说明。候选存在性已对照官网公开浏览目录核对，尚未将“名称对应”视为外观验收通过。

覆盖选择列表、当前录入项目、进食／运动历史、减个肥页面的当日食物与运动明细。营养结构中的鸡肉、米饭、黄油等食材图示可在同一轮替换。底部导航、设置、日历、体重／体脂、按钮和其他功能图标维持现状。

## 授权与素材来源

截至 2026-10-21，[Thiings 官方条款](https://www.thiings.co/terms)规定免费单图下载用于个人／非商业用途且需署名；用于商业 App 的授权属于付费档。Indie 标价一次性 **49 美元**，适用范围和企业年营收门槛以购买时的官方条款为准；更高营收规模有其他档位。

用户确认目前尚未购买，本轮仅准备方案。清单只引用官网公开目录的名称和链接，**未下载图标图片、未导入 App 素材、未修改产品代码、未购买授权、未发布新构建**。审阅页面也不嵌入未获商用授权的图像。

来源：[Collection](https://www.thiings.co/things)、[公开浏览目录](https://www.thiings.co/api/catalog?v=3f32e2f010c5)、[About](https://www.thiings.co/about)、[Terms](https://www.thiings.co/terms)。本地方案不复制整套 10,000 项目录，仅保留本 App 需要的候选信息。

## 授权后的接入方式

1. 从授权包挑选并目视核对候选。先处理 143 个近似项及 12 个待选型项，避免把整鸡当鸡胸、其他坚果当夏威夷果、其他动作当指定训练。
2. 只导入最终选定素材到 `Assets.xcassets`，使用透明底 PNG。为现有约 22–30 pt 的图标位置准备足够的像素尺寸；等比例显示，不拉伸、不裁切主体，不改变行高和点击区域。包体增量以真实导入后的构建测量为准。
3. 增加统一 `ThiingsIconCatalog`，以稳定的食材／运动 ID 关联本地 asset。`AppState.foodIcon(...)`、`exerciseIcon(...)` 优先返回已导入的 asset 引用；`AppIconBadge` 增加本地图片渲染分支。现有选择器、录入行和历史明细共用该入口。
4. 采用显示层映射，保留原有数据库 ID、图标字符串和历史记录。旧版本留下的 emoji 不会导致新版本继续显示旧图；不需要重写用户记录或触发全量同步。
5. 自定义项目按真实类别选择同系列通用图示；缺素材或无法可靠解析时保留可识别的回退图示，并纳入覆盖清单，不显示空白。
6. 图标随安装包离线加载，列表滚动时不逐行访问 Thiings 网站。资源尺寸和解码开销在导入时控制，避免 3D 素材拖慢列表。

## 验收与发布

- 完整映射测试：398 个内置项目均能解析到存在的最终资源；任何近似映射都有明确选型结论；无空白图标。
- 旧数据测试：已有饮食／运动记录、自建项目、跨月历史、自然语言识别结果和英文名称显示都正确，营养和 MET 数值保持原值。
- 视觉测试：浅色／深色、普通／小屏、DUO 外屏与内屏、字体放大下检查主体清晰度、透明边缘、对齐、行高和文字间距。
- 交互与性能测试：选择、搜索、录入、历史列表滚动和横竖屏切换；构建后测量实际包体及首次进入列表的开销。
- 沿用当前 1.1.0（2）作为产品基线。授权和选型完成、构建及截图验证通过后再创建新的 TestFlight 构建；本轮不递增版本。

## 清单再生成

`prepare_plan.py` 仅读取源码和已有的官网公开浏览目录 JSON，输出候选元数据；不会下载任何图标图片：

```sh
python3 124_Design/Thiings/prepare_plan.py --catalog /path/to/public-catalog.json
```
